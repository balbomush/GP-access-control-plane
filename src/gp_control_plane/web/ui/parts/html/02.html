0
Создает одну защищенную локальную копию для отдельного сценария чистой установки. Сервис автоматически сохраняет защищенный device-local handoff вне очищаемых GP-данных; для восстановления выберите vault и явно подтвердите восстановление с удалением источника.

Опасные действия

Восстановление, удаление данных, обновления и изменение настроек недоступны во время активного подбора.
